## 🚀 Como Publicar

### Opção 1: Hospedagem Compartilhada (cPanel, Plesk, etc.)
1. Extraia o arquivo ZIP
2. Faça upload de TODOS os arquivos para a pasta `public_html` do seu servidor
3. Acesse seu domínio no navegador

### Opção 2: Netlify (Recomendado - Grátis)
1. Acesse [netlify.com](https://www.netlify.com)
2. Faça login ou crie uma conta
3. Arraste a pasta `geupc-reboque-html` para a área de upload
4. Seu site estará online em minutos

### Opção 3: Vercel (Recomendado - Grátis)
1. Acesse [vercel.com](https://www.vercel.com)
2. Clique em "New Project"
3. Selecione "Other" e faça upload da pasta
4. Seu site estará online

### Opção 4: GitHub Pages (Grátis)
1. Crie um repositório no GitHub
2. Faça upload de todos os arquivos
3. Vá em Settings → Pages
4. Selecione "Deploy from a branch" e escolha `main`
5. Seu site estará em `https://seu-usuario.github.io/seu-repositorio`
